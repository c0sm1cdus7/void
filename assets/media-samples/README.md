# Original VOID media samples

These four files are generated by `scripts/generate-media-samples.ts` and covered by VOID's MIT license. They contain no downloaded music, footage or third-party artwork.

- `motion-study.webm`: six-second silent 640×360 VP8 canvas animation.
- `motion-study.png`: its uncompressed source poster. The DESERT image pipeline serves optimized WebP thumbnails and previews.
- `motion-study.vtt`: English visual-description caption; the video contains no speech or sound.
- `quiet-tones.wav`: eight seconds of synthesized tones, mono 24 kHz PCM. No embedded artwork.

The host binds these originals by explicit asset reference. The public build attests their hashes but does not copy host paths. Apple's separate local Landmarks reference photographs are not covered by this license and are not copied into this directory.
